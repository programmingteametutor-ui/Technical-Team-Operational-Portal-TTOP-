Users & Roles is the single onboarding point. One email can hold multiple active roles at the same time. Selecting Handler, Setup Support or Technical Support automatically creates/links the corresponding stable resource identity. Technical Support is one common sector; Developer and Screen Operator are capabilities/duties, not separate portal roles. Each user can switch between only their assigned roles from the Current Role dropdown without logging in again.

New Handler identities are created from Users & Roles. This tab is for Handler-specific configuration only: Team, Shift Start, Shift End, Active and Notes. Shift values are stored as time-only text; for example 11:00 AM → 5:00 AM means the shift ends the next day.
Setup Support members are created automatically from Users & Roles. This list shows their stable Support ID, email and supported team. Hyderabad remains Self Support.
Technical Support is one shared sector. Each member can be marked Developer, Screen Operator, or Both. On an individual call, Developer Assigned To and Screen Access Assigned To remain separate duties, but both are selected from this same Technical Support roster.
